FAQ

Questions teachers usually ask before trying it

Clear answers for the core use cases, device support, and export workflow.

Do I need to install anything?

No. TeachSheet AI runs in the browser, so teachers can start generating worksheets without local setup.

Does it work on mobile?

Yes. The interface is responsive, although the full worksheet building workflow is more comfortable on desktop.

Can I export to PDF?

Yes. Worksheets can be exported as printable A4 PDFs with margins, layout structure, and answer sheets.

Can I save projects?

Yes. Signed-in users can keep worksheets linked to their account and reopen them for later editing or reuse.
